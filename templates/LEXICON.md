# Lexicon

This file is the project dictionary for STE and STE-C (rule C9.1).
Each word in it has one meaning in the whole project.
The STE checker reads the tables in this file.

Add a row when you use a new domain word.
A word in the "Technical nouns" table or the "Technical verbs" table overrides the words-to-avoid list of the standard.

## Examples of rows

- Technical noun: `invoice` is a request for payment that the billing service sends to a customer.
- Technical verb: `reconcile` means to match a ledger entry with a bank transaction.
- Approved abbreviation: `sku` is a stock keeping unit.
- Word to avoid: `client`. Use `customer` for a person who pays, and `apiClient` for code.
