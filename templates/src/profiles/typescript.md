## TypeScript and JavaScript

- Use camelCase for functions and values, and PascalCase for types and React components (C8.4).
- Write an acronym as one word: `HttpClient`, `userId` (C8.4).
- A React component is a noun. A hook starts with `use`. An event prop starts with `on` (C3.1).
- Use `handle` only for an event callback in a `.tsx` or `.jsx` file (C1.6).
- Do not write JSDoc or TSDoc blocks (C6.2).
- Return `T | null` or a result type for an expected failure (C6.5).
- Run ESLint with `eslint.config.mjs` from the STE linters (`linters/typescript`).
