# Lexicon

This file is the project dictionary of this repository (rule C9.1).
Each word in it has one meaning in the whole repository.

## Technical nouns

| Word | Meaning |
|---|---|
| `rule` | One W rule or C rule, with an ID such as W5.1 or C6.1. |
| `finding` | One break of one rule at one line of one file. |
| `profile` | The idioms and the exceptions for one language, or the template for one type of repository. |
| `lexicon` | The project dictionary in LEXICON.md. |
| `fixture` | A test file that breaks rules on purpose (bad) or obeys them (good). |
| `directive` | A comment that a tool reads, such as `# noqa`. It is not prose. |
| `suppression` | A directive that tells the checker to skip a rule on a line. |
| `token` | A comment or a string literal that the source scanner finds. |
| `block` | A paragraph, a list item, or an alert in a Markdown file. |
| `marker` | WARNING, CAUTION, or NOTE at the start of a notice. |
| `hedge` | A word that states doubt, such as "may" or "probably". |
| `recipe` | The list of fragments that the build joins into one AGENTS.md template. |
| `mirror` | A folder that the build copies into the assets of a skill. |
| `drift` | A difference between a generated file on disk and the build output. |

## Technical verbs

| Word | Meaning |
|---|---|
| `ask` | Show a question to the user, and read the answer. |
| `select` | Choose items from a list, from the command options or from the answers of the user. |
